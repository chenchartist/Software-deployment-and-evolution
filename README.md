Software Deployment and Evolution

Task 1.1 or SampleApp
SampleApp is a basic C# console application that displays a message. It demonstrates the fundamentals of creating and packaging a Windows application using WiX Toolset.

#instalation
1. go to SampleApp folder and there will be WixExample folder go in go to bin/release/ and then find the Window Installer or WixExample
2. click on it and wait for the download
3. go to C drive
4. find program files and then find WixExample
5. Run the Application


Task 1.2, 1.3 or CustomApp
1.2, 1.3 is a basic Text processor or word counter app, using c# and Wix Toolset.

both 1.2 and 1.3 is creating a windows desktop application, packaging with Wix Installer
but 1.3 has multiple DLL dependencies (TextProcessorLibraries and TextProcessorUtils)

#Usage
1. Open text processor
2. paste or type in the text box
3. click on the count word button
4. view on the word count result

#Project Structure
1. Main Application (TextProcessor)
2. TextProcessorLibrary: Word counting library
3. TextProcessorUtils: Text Validation Library
